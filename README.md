# Digital Forensics Lab

**Advanced digital forensics and incident response toolkit** with focus on memory analysis, evidence preservation, and malware investigation.

## 🔬 Overview

Custom Linux-based forensic environment and tools used in real-world data recovery and cybersecurity investigations.

## 🛠️ Key Tools & Scripts

- Memory dump analysis
- Evidence acquisition and hashing
- Malware static/dynamic analysis
- Timeline generation
- Court-admissible evidence workflows
